# Scientific Exam Maker
The Scientific Exam Maker is a powerful AI-assisted tool designed to help educators create customized scientific exams quickly and efficiently. This tool leverages advanced language models to generate high-quality calculation-based problems in subjects like Mathematics, Physics, and Chemistry, saving you time while ensuring educational standards are met.

## Overview
Scientific Exam Maker allows you to:

- Generate complete scientific exams with customizable calculation-based problems
- Specify the number of questions, difficulty level, and point distribution
- Set the context level for problems (none, medium, or very detailed)
- Upload reference materials to guide the exam content
- Preview the generated exam with formatted text
- Download the generated exams as PDF or Word documents
- Save exams directly to your classroom materials

## Getting Started
To access the Scientific Exam Maker tool:

1. Log in to your Maestre account
2. Navigate to the Tools section
3. Select "Scientific Exam Maker" from the available tools

Note: You must have at least one classroom created to use this tool. If you don't have any classrooms, you'll be prompted to create one first.

## Creating a Scientific Exam
### Basic Settings
1. Subject: Enter the scientific subject for your exam (e.g., Mathematics, Physics, Chemistry)
2. Exam Name: Give your exam a descriptive title
3. Number of Questions: Select how many calculation-based problems to include
4. Difficulty Level: Set the difficulty from 1-10
5. Context Level: Choose how much context to include in problems:
   - None: Direct exercises with minimal context
   - Medium: Problems with moderate context
   - Very Much: Extended problems with rich context and multiple pieces of information
6. Total Points: Set the total point value for the exam
7. Classroom: Select which classroom this exam is for

### Advanced Options
- Equal Distribution: All questions are worth the same number of points
- Custom Distribution: Specify different point values for different questions
- Additional Instructions: Add any specific requirements or guidelines for the exam

### AI Model Selection
Choose from available language models to generate your exam:

- Llama 3.2 (3B parameters) - Faster generation, good for basic exams
- Other available models may vary based on your system configuration

## Adding Reference Materials
You can provide reference materials to guide the content of your scientific exam:

### Upload a File
1. Click the "Upload File" button
2. Select a DOCX file from your computer
3. The file will be processed and used as reference for exam generation

### Use Classroom Materials
1. Click "Select from Classroom Materials"
2. Choose a DOCX file from your existing classroom materials
3. The selected material will be processed and used as reference

Note: Only DOCX files under 5MB are supported for reference materials.

## Generating the Exam
1. Review all your settings to ensure they match your requirements
2. Click the "Generate Exam" button to start the creation process
3. Wait while the AI generates your scientific exam (this may take a few moments)

## Working with Generated Exams
Once your exam is generated, you'll see a preview with formatted text. From here, you can:

### Export Options
- Download as Word: Save the exam as a Word document
- Save to Classroom: Upload the exam directly to your selected classroom as a material
- Copy to Clipboard: Copy the exam text to paste elsewhere

### Regenerate
If you're not satisfied with the results, you can:

- Adjust your settings
- Provide more specific instructions
- Click "Regenerate" to create a new version

## Tips for Best Results
1. Be Specific: The more detailed your subject and instructions, the more targeted your exam will be
2. Provide References: Uploading reference materials significantly improves the relevance of generated problems
3. Start Simple: Begin with a smaller number of questions and basic settings before creating more complex exams
4. Review Carefully: Always review generated content for accuracy and appropriateness before using with students
5. Use the appropriate context level for your educational needs:
   - "None" for direct calculation exercises
   - "Medium" for problems with some real-world context
   - "Very Much" for complex word problems with multiple data points

## Troubleshooting
- Error Messages: Pay attention to any alert messages that appear during the process
- File Processing Issues: Ensure your reference files are in DOCX format and under 5MB
- Generation Failures: If exam generation fails, try using a different AI model or simplifying your requirements
- Formula Display: All mathematical formulas are rendered in ASCII format in the generated exam

## Language Support
The Scientific Exam Maker supports the following languages:

- English
- Spanish

The language of your generated exam will match the language selected in your application settings.

## Privacy and Data Security
- All uploaded materials and generated exams are processed securely
- Reference materials are only used for the current exam generation session
- Generated exams are not stored on our servers unless you explicitly save them to your classroom
