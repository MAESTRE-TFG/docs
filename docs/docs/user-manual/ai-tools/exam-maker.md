# Exam Maker
The Exam Maker is a powerful AI-assisted tool designed to help educators create customized exams quickly and efficiently. This tool leverages advanced language models to generate high-quality exam content based on your specifications, saving you time while ensuring educational standards are met.

## Overview
Exam Maker allows you to:

- Generate complete exams with customizable questions and formats
- Specify the number of questions, question types, and point distribution
- Upload reference materials to guide the exam content
- Preview the generated exam with formatted text
- Download the generated exams
- Save exams directly to your classroom materials
## Getting Started
To access the Exam Maker tool:

1. Log in to your Maestre account
2. Navigate to the Tools section
3. Select "Exam Maker" from the available tools
Note : You must have at least one classroom created to use this tool. If you don't have any classrooms, you'll be prompted to create one first.

## Creating an Exam
### Basic Settings
1. Subject : Enter the subject for your exam (e.g., Mathematics, History, Science)
2. Exam Name : Provide a name for your exam (e.g., "Midterm Exam", "Chapter 3 Quiz")
3. Classroom : Select the target classroom from your available classrooms
4. Number of Questions : Specify how many questions you want in your exam
5. Question Type : Choose from available question formats.
6. Total Points : Set the total point value for the exam

### Advanced Options
- Equal Distribution : All questions are worth the same number of points
- Custom Distribution : Specify different point values for different questions or question types Reference Materials
- Upload File : Upload a DOCX file containing reference material (syllabus, lecture notes, exercises, etc.)
- Select from Classroom : Choose an existing DOCX file from your classroom materials
- Remove : Remove any uploaded reference materials if needed
Note : Only DOCX files under 5MB are supported for reference materials.

### AI Model Selection
Choose from available language models to generate your exam:

- Llama 3.2 (3B parameters) - Faster generation, good for basic exams
- Other available models may vary based on your system configuration
## Generating the Exam
1. Review all your settings to ensure they match your requirements
2. Click the "Generate Exam" button to start the creation process
3. Wait while the AI generates your exam (this may take a few moments)
## Working with Generated Exams
Once your exam is generated, you'll see a preview with formatted text. From here, you can:

### Export Options
- Download as PDF : Save the exam as a PDF file to your device
- Save to Classroom : Upload the exam directly to your selected classroom as a material
- Copy to Clipboard : Copy the exam text to paste elsewhere
### Regenerate
If you're not satisfied with the results, you can:

- Adjust your settings
- Provide more specific instructions
- Click "Regenerate" to create a new version
## Tips for Best Results
1. Be Specific : The more detailed your subject and instructions, the more targeted your exam will be
2. Provide References : Uploading reference materials significantly improves the relevance of generated questions
3. Start Simple : Begin with a smaller number of questions and basic settings before creating more complex exams
4. Review Carefully : Always review generated content for accuracy and appropriateness before using with students
## Troubleshooting
- Error Messages : Pay attention to any alert messages that appear during the process
- File Processing Issues : Ensure your reference files are in DOCX format and under 5MB
- Generation Failures : If exam generation fails, try using a different AI model or simplifying your requirements
## Language Support
The Exam Maker supports the following languages:

- English
- Spanish

The language of your generated exam will match the language selected in your application settings.

## Privacy and Data Security
- All uploaded materials and generated exams are processed securely
- Reference materials are only used for the current exam generation session
- Generated exams are not stored on our servers unless you explicitly save them to your classroom
