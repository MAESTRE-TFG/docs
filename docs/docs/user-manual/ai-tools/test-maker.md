# Test Maker
The Test Maker is a powerful AI-assisted tool designed to help educators create customized tests quickly and efficiently. This tool leverages advanced language models to generate high-quality test content based on your specifications, saving you time while ensuring educational standards are met.

## Overview
Test Maker allows you to:

- Generate complete tests with customizable questions and formats
- Specify the number of questions, question types, and point distribution
- Upload reference materials to guide the test content
- Preview the generated test with formatted text
- Download the generated tests
- Save tests directly to your classroom materials

## Getting Started
### Basic Setup
1. **Subject**: Enter the subject for your test
2. **Test Name**: Provide a name for your test (optional)
3. **Number of Questions**: Select how many questions you want in your test
4. **Question Type**: Choose from multiple choice, true/false, or other formats
5. **Classroom**: Select the classroom this test is for
6. **Total Points**: Set the total point value for the test

### Advanced Options
- **Number of Answer Options**: For multiple choice questions, specify how many options each question should have
- **Scoring Style**: Choose between equal distribution or custom point allocation
- **Custom Scoring Details**: If using custom scoring, specify how points should be distributed
- **Additional Instructions**: Add any specific requirements or instructions for the test

## Adding Reference Materials
You can provide reference materials to guide the content of your test:

### Upload a File
1. Click the "Upload File" button
2. Select a DOCX file from your computer
3. The file will be processed and used as reference for test generation

### Use Classroom Materials
1. Click "Select from Classroom Materials"
2. Choose a DOCX file from your existing classroom materials
3. The selected material will be processed and used as reference

## Generating Your Test
1. Fill in all required fields (Subject and Classroom are mandatory)
2. Add any reference materials if needed
3. Click "Generate Test"
4. Wait while the AI creates your test based on your specifications

## Working with Generated Tests
### Regenerate
If you're not satisfied with the results, you can:

- Adjust your settings
- Provide more specific instructions
- Click "Regenerate" to create a new version

### Save and Export
Once you're happy with your test, you can:

- Download it as a PDF
- Save it directly to your classroom materials
- Edit the content if needed before saving

## Tips for Better Results
- Be specific with your subject and instructions
- Provide relevant reference materials for more targeted questions
- Use the custom scoring option for tests with varying question difficulty
- Specify the number of answer options for multiple choice questions
- Include any special formatting requirements in the additional instructions

## Troubleshooting
- Error Messages: Pay attention to any alert messages that appear during the process
- File Processing Issues: Ensure your reference files are in DOCX format and under 5MB
- Generation Failures: If test generation fails, try using a different AI model or simplifying your requirements

## Privacy and Data Security
- All uploaded materials and generated tests are processed securely
- Reference materials are only used for the current test generation session
- Generated tests are not stored on our servers unless you explicitly save them to your classroom
